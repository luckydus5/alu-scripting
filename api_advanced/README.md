# API Advanced

Advanced usage of the Reddit API using recursive Python requests.

- `0-subs.py`: Returns the number of subscribers in a subtree.
- `1-top_ten.py`: Prints the first 10 hot posts listed for a subreddit.
- `2-recurse.py`: Recursively fetches the titles of all hot articles.
- `3-count.py`: Recursively queries the Reddit API, parses the title of all hot articles, and prints a sorted count of given keywords.
